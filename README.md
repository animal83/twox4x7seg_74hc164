# twox4x7seg_74hc164
4 digits dual 7-segment display 74hc164(B)



## 📌 Übersicht

Dieses Projekt ermöglicht die Ansteuerung eines 4-stelligen Dual-7-Segment-Displays mithilfe von 74HC164 Schieberegistern. Es eignet sich ideal für Arduino-Projekte, bei denen mehrere Ziffern angezeigt werden sollen, ohne viele I/O-Pins zu belegen.

---

## ⚙️ Hardware-Anforderungen

- **2 × 74HC164 Schieberegister**
- **4-stelliges Dual-7-Segment-LED-Display**
- **Arduino-kompatibles Board** (z. B. Arduino Uno, Nano)
